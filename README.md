# 💻 Projeto: Sistema de Login / Landing Page

Olá! Este projeto tem como objetivo principal ajudar pessoas que estão iniciando na carreira de programação, assim como eu. 
Durante meus estudos em **desenvolvimento front-end**, decidi criar este projeto para colocar em prática o que venho aprendendo e, ao mesmo tempo, colaborar com outros iniciantes que enfrentam dificuldades semelhantes.

## 🚀 Tecnologias utilizadas
- HTML
- CSS
- JavaScript
-------------
