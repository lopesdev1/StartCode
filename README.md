# 💻 Projeto: Sistema de Login / Landing Page

Olá! Este projeto tem como objetivo principal ajudar pessoas que estão iniciando na carreira de programação, assim como eu. 
Durante meus estudos em **desenvolvimento front-end**, decidi criar este projeto para colocar em prática o que venho aprendendo e, ao mesmo tempo, colaborar com outros iniciantes que enfrentam dificuldades semelhantes.

## 🚀 Tecnologias utilizadas
- HTML
- CSS
- JavaScript
-------------
## 🛠 Funcionalidades
- Modo escuro (Dark Mode) com JavaScript
- Responsividade para dispositivos móveis (ainda em melhorias)
-------------
## 🔄 Próximas implementações
- Sistema de login com integração a banco de dados
- Sistema de cadastro de usuários
- Melhorias na responsividade para diferentes tamanhos de tela
- Validações de formulário no front-end e back-end
- Feedback visual de erros (como "usuário não encontrado", "senha incorreta", etc.)
-------------
**Imagens usada nesse projeto estão sendo utilizada apenas para fins educacionais e aprendizado.**
